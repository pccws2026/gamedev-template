# 要件定義書

## 1. どんなゲームか？

「右からやってくる敵を倒しながら進み、最後のボスを倒すとクリアのシューティングゲーム」

操作：矢印キーで上下に動き、スペースキーで弾を発射

## 2. 勝ち条件 / 負け条件

- 勝ち：最後に出てくるボスのHPを0にするとクリア
- 負け：敵や敵の撃つ弾に当たり、HPが0になるとゲームオーバー

## 3. 作らないもの

- BGMと効果音なし
- ステージは1面のみ
- セーブやランキングなし

## 4. これができたら完成

1. プレイヤーは矢印キーで上下に動かせ、スペースキーで弾を発射できる
2. 敵にプレイヤーの出した弾を当てると敵のHPが減り、0になると消滅
3. ボスのHPを0にするとクリア
4. 敵本体や敵の撃つ弾に当たるとプレイヤーのHPが減り、0になるとゲームオーバー

## 5.その他仕様

- ゲーム内の時間単位として60fを1秒として扱う。
実際のフレームレートが変動しても、経過時間に応じて処理する。
- 当たり判定は、オブジェクトの見た目と同じにする
- プレイヤーは上下にのみ動かせる
- 雑魚敵は右端から出現し、左へ動く
- 雑魚敵は同時に画面に存在できる数が5体までである
- 敵の弾は、雑魚敵の左端中心、ボス左端最上部、中心、最下部からも撃たれ、左へ動き続ける
- プレイヤーの弾は、プレイヤーの右端中心から撃たれ、右へ動き続ける
- プレイヤーは弾を放つ際、長押しなら一定間隔で弾を放つ
- 5f以上20f以内の間隔でスペースキーを連打した場合、スペースキーを押すたびに弾を発射する。最大5fごとに弾を発射できる
- 雑魚敵、敵の弾、プレイヤーの弾、ともに画面端へ触れると消失する（この際、雑魚敵の消失は撃破でないため、得点にはならない）
- 敵の弾はプレイヤーに触れた場合も消失する
- プレイヤーの弾は雑魚敵やボスに触れた場合も消失する
- 弾は、上限に達している場合、既存の弾が消失するまで出現しない
- ボスはゲーム開始後1200fに画面右端から出現し、左方向へ300ピクセルを1秒書けて移動する。
- 進み終わった時点でプレイヤーの弾が当たるようになり、攻撃を開始する
- その後はx座標を固定する
- ボス出現時の雑魚敵や敵の弾は変わらず存在するが、出現後からは雑魚敵は出現しなくなる
- ボスは撃破してクリアするか、ゲームオーバーになるまで消失しない
- ボスは攻撃を開始してからはx座標は変化しないため、プレイヤーと接触することはない
- ボスには行動パターンが2種あり、ボスが300ピクセル移動してから一定時間毎にAとBを交互に切り替える。初めはパターンAから始まる。
- 行動パターンA : 常にy方向へ移動し、弾を発射する。画面端へ触れると切り返す。初めに動く方向はランダム。
- 行動パターンB : 常にプレイヤーのY座標を追尾し、プレイヤーのY座標に合わせて弾を発射する。
- ボスはHPが20以下になった瞬間、前半から後半へ切り替える
- ボスは前半と後半で弾発射の待ち時間と移動速度、発射する弾が変化する
- 前半、後半の切り替えと行動パターンの変化は別々で扱う
- 前半、後半、どちらでも行動パターンの切り替えは同じように起きる
- 後半のみ、前半の3発に加えそれぞれの弾の間からも弾を放ち、5発撃つようにする
- スコア、経過時間はタイトルに戻った際すべてリセットする
