# 要件定義書

# 1. どんなゲーム？

マウスを使って的を撃ち抜くゲーム

## 2. 勝ち条件 / 負け条件

**ゲームが始まり30秒たったら勝利条件を判定する。**

- 勝ち：30000点以上獲得したらクリア画面へ
- 負け：30000点未満ならゲームオーバー画面へ

## 3. 作らないもの

- BGMはなし
- ステージは1つだけ。2面以降は作らない
- セーブ機能・ランキングは作らない

## 4. これができたら完成

- マウスの左クリックで射撃する
- 射撃は0.2秒のクールダウンを要する
- スコアと残り時間を常時表示する
- 的は0.5秒間隔でランダムな位置に出現し、4秒で消滅する
- 的の出現間隔は、プレイ開始時の0.5秒から時間経過に応じて短くなり、制限時間終了時には0.1秒間隔になる
- 的は左右方向、上下方向、または左右と上下の両方に移動する。移動方向は出現時にランダムに決定し、移動中は変化しない
- 的ごとの移動速度は出現時に100から300px/sの範囲でランダムに決定し、移動中は変化しない
- 的の半径は33.6pxとする
- 的は白色とオレンジ色の、大きさの異なる円が交互に重なった見た目とする
- 出現するオブジェクトの25%を爆弾に変更する
- 爆弾は的と同じ大きさで、黒一色の円に白い縁を付けた見た目とする

## 5. 細かい定義

- 的が射撃時に少しでも射撃カーソルにふれていたら撃破判定とする
- 的を撃破した時は、現在の爆発アニメーションだけを表示する
- 爆弾を撃破すると爆発して消滅する
- 爆弾は自然消滅しない
- 爆発範囲は爆弾の半径の6.5倍の円形とする
- 爆発時は爆発範囲を示す爆弾アニメーションを0.2秒間、より不透明に表示する
- 爆発範囲内の的および爆弾を撃破判定とする
- 爆発に巻き込まれた的にも、的の撃破アニメーションを表示する
- 爆発に巻き込まれた爆弾は連鎖して爆発する
- 爆弾自体は撃破数に含めず、爆発に巻き込まれた的だけを撃破数に含める
- 撃破された的はその場で消滅する(同じ的が複数回撃破されることはない)
- 射撃クールダウン時にクリックしても反応はなし、クールダウンタイムも変更なし
- HUDや他の的とは重ならないように出現する
- 的がHUDと重ならない範囲の端に到達した場合は反射する
- 移動中に的同士が重なった場合は反射する
- 的が自然消滅する際はフェードアウトする
- プレイ中のみに的と射撃カーソルが表示する
- HUDは画面上に表示する(左に枚数,右に秒数で同じ行で表示)
- HUDのフォントは等幅フォントを使用する
- 枚数は「n枚撃破」と表示
- 残り時間の表式は秒の小数第一まで表示
- タイトルへ戻った際は、ゲームの状態を初期化する
- タイトル画面は中央にゲームタイトルとその下に「スペースキーで始める」と表示
- ゲームクリア画面は「ゲームクリア」とその下に「スペースキーでタイトルへもどる」と表示
- ゲームオーバー画面は「ゲームオーバー」とその下に「スペースキーでタイトルへもどる」と表示
- ゲームクリア画面とゲームオーバー画面は、スコアを画面中央下に「n点」の形式で表示する
- 的を1個撃破すると、コンボ数を1増やし、100点にコンボ数を掛けたスコアを加算する
- 爆弾を撃破してもスコアは加算しないが、コンボは継続する
- 的を撃破してから2秒以内に次の的を撃破できなかった場合、コンボを0にする
- 的や爆弾に射撃を外した場合、コンボを0にする
- コンボ数を射撃時にカーソルの横へ表示し、2秒後に消す
- プレイ中に表示するすべての文字のサイズを変更前の1.8倍にする
- 的を撃破した時は、スコアの下に「+n点」を1秒間表示してからスコアへ加算する
