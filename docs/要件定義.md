# 要件定義書

## 1. どんなゲームか？

「右からやってくる敵を倒しながら進み、最後のボスを倒すとクリアのシューティングゲーム」

操作：矢印キーで上下に動き、スペースキーで弾を発射

## 2. 勝ち条件 / 負け条件

- 勝ち：最後に出てくるボスのHPを0にするとクリア
- 負け：敵や敵の撃つ弾に当たり、HPが0になるとゲームオーバー

## 3. 作らないもの

- BGMと効果音なし
- ステージは1面のみ
- セーブやランキングなし

## 4. これができたら完成

1. プレイヤーは矢印キーで上下に動かせ、スペースキーで弾を発射できる
2. 敵にプレイヤーの出した弾を当てると敵のHPが減り、0になると消滅
3. ボスのHPを0にするとクリア
4. 敵本体や敵の撃つ弾に当たるとプレイヤーのHPが減り、0になるとゲームオーバー

## 5.その他仕様

- プレイヤーは上下にのみ動かせる
- 雑魚敵は右端から出現し、左へ動く
- 敵の弾は、雑魚敵とボスの左端中心から撃たれ、左へ動き続ける
- プレイヤーの弾は、プレイヤーの右端中心から撃たれ、右へ動き続ける
- プレイヤーは弾を放つ際、長押しなら一定間隔で、連打ならそれより早く放つことが加納である
- 雑魚敵、敵の弾、プレイヤーの弾、ともに画面端へ触れると消失する（この際、雑魚敵の消失は撃破でないため、得点にはならない）
- ボスは時間経過で右から出現し、撃破しクリア、もしくはゲームオーバーまで消失しない
- ボスには行動パターンが2種あり、一定時間毎に切り替わる
- 行動パターンA : 常にy方向へ移動し、弾を発射。画面端へ触れると切り返す
- 行動パターンB : 常にプレイヤーの動きを追尾し、弾を発射
- ボスは前半と後半で弾発射の待ち時間と移動速度が変化する
