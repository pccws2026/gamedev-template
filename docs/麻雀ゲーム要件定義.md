# 麻雀ゲーム要件定義書

## 1. 目的と概要

- ゲームタイトルは「二人麻雀」とする。
- ファミコン風の「麻雀」を基準にした、レトロな画面構成・色使い・情報配置とする。
- プレイヤー1人とCPU1人が対戦する二人打ち麻雀とする。
- 既存の的あてゲームとは別のゲームとして提供する。
- 既存ゲームと完全に分離し、URL `/double_maajan` で起動できるようにする。
- 既存作品の画像・音声・固有素材は使用せず、オリジナルの画面と素材で実装する。
- BGM・効果音は使用しない。

## 2. 対局ルール

### 2.1 基本形式

- リーチ麻雀のルールを採用する。
- 符の計算は行わず、30符相当の点数表を使用する。
- 通常の136枚を使用し、赤ドラは使用しない。
- 東風戦とし、東一局から東四局まで行う。
- 東一局の最初の親はランダムに決定する。
- 親は、親があがった場合のみ連荘する。
- 流局時は局を終了し、親を交代する。
- 山の牌がなくなった場合は流局とする。
- 九種九牌、四風連打、四開槓などの特殊流局はすべて使用しない。
- 流局時の点数の受け渡しは行わない。
- 東四局終了後に対局を終了する。

### 2.2 配牌とツモ

- 対局開始時の持ち点は、親・子ともに25,000点とする。
- 親は最初から14枚、子は13枚を配牌する。
- 親は手牌から1枚捨てて対局を開始する。
- プレイヤーは「ツモる」ボタンをクリックして山から牌を1枚引く。
- ツモった牌は、配牌された牌から少し離して表示する。
- 山の牌がなくなった時点でツモ操作を終了し、流局へ進む。

### 2.3 役とあがり

- 一般的なリーチ麻雀の役をすべて使用する。
- リーチ、ダブルリーチ、一発、ドラ、ロン、ツモを使用する。
- 裏ドラは使用しない。
- カンドラは使用しない。
- 食い下がりを使用する。
- 役なしではあがれない。
- フリテンではロンできないが、ツモはできる。
- 食い替えは禁止する。
- 同じ牌が4枚すべて見えている場合、その牌は待ち牌候補に残すが、あがり不可とする。
- 複数の役満が成立しても、役満1つ分として扱う。
- ダブル役満は使用しない。
- チョンボは実装せず、無効な操作として扱う。

### 2.4 鳴き

- ポン・チー・カンを使用する。
- プレイヤーは、鳴き可能時に表示される対応ボタンをクリックして鳴く。
- 複数の鳴きパターンがある場合は、鳴きに使用する牌をクリックして選択する。
- 鳴き可能な場面で鳴かない場合は、牌をクリックしてスキップする。
- プレイヤーが鳴いた牌は、手牌の右側に分けて公開する。
- CPUが鳴いた牌は、手牌の左側に分けて表向きで表示する。
- 二人麻雀のため、鳴き牌はすべて同じ向きで表示する。

### 2.5 リーチ

- リーチ可能なときは「リーチ」ボタンを表示し、クリックして宣言する。
- CPUはリーチ可能かを自動判定し、可能な場合は自動でリーチを宣言する。
- プレイヤーがリーチした後は自動でツモ切りする。
- CPUがリーチした後は自動でツモ切りする。
- 鳴いた牌とリーチ後の牌は表向きで表示する。
- リーチ後もロン・ツモ可能な場合は、対応するボタンを表示する。

### 2.6 リーチ棒

- リーチ棒のみ使用し、積み棒は使用しない。
- リーチ宣言時に宣言者が1,000点を支払う。
- あがった場合、あがりプレイヤーがリーチ棒をすべて受け取る。
- 供託リーチ棒が複数ある場合も、あがりプレイヤーがすべて受け取る。
- 流局時は、リーチ棒をリーチ宣言者へ返す。

## 3. 点数計算

### 3.1 基本方針

- 指定された30符相当の簡易点数表を使用する。
- 先に提示された別の点数表は使用しない。
- 画像にない翻数は、5翻を満貫、7翻を跳満、9・10翻を倍満、12翻を三倍満として扱う。

## 4. CPUの動作

- CPUは手牌の完成しやすさを判断して、捨て牌を選ぶ。
- CPUは手牌の完成しやすさを判断して、鳴きやリーチを自動で選択する。
- CPUはロン・ツモの可否を自動判定し、あがれる場合は自動であがる。
- CPUは手牌を自動で整理する。
- CPUはプレイヤーが鳴き・ロン・ツモをスキップするまで待機する。
- CPUはプレイヤーが牌を捨てた後、すぐにツモ・鳴き・あがりを判定する。
- CPUの思考中表示は行わない。
- CPUの手牌はすべて裏向きで表示する。
- CPUの手牌は裏向きの牌を横一列に並べ、ツモった牌は少し離して表示する。

## 5. プレイヤー操作

- 手牌から牌をクリックして選択し、同じ牌をもう一度クリックして捨てる。
- プレイヤーの手牌は自動で種類・数字順に並べる。
- 選択中の牌は少し上へ移動して表示する。
- ロン・ツモ可能なときは対応するボタンを表示し、クリックしてあがる。
- 鳴き・ロン・ツモのボタンは、次のゲーム処理が発生するまで表示する。
- 鳴き可能時に鳴かない場合は、牌をクリックしてスキップする。

## 6. 画面・表示仕様

### 6.1 画面遷移

- 起動時はタイトル画面とする。
- タイトル画面の中央に「二人麻雀」と「クリックで始める」を表示する。
- タイトル画面をクリックすると対局を開始する。
- 対局終了時はゲームクリア画面またはゲームオーバー画面へ遷移する。
- 終了画面の中央に結果、親・子の最終持ち点、勝敗を表示する。
- 終了画面に「クリックでタイトルへもどる」と表示する。
- 終了画面をクリックするとタイトル画面へ戻る。
- 同点の場合は引き分けとする。
- あがり・流局の局終了後は結果を表示し、クリックで次局へ進む。
- 流局時は結果を表示しないが、クリックで次局へ進む。

### 6.2 対局画面

- 対局画面の背景色は濃い緑色とする。
- 局数と親を常時表示する。
- プレイヤーの持ち点は画面下部、CPUの持ち点は画面上部に表示する。
- 牌山は画面中央に表示する。
- 牌山の残り枚数と「ツモる」ボタンを表示する。
- ドラ表示牌は牌山の横に表向きで表示する。
- 操作ボタンは画面下部に横一列で表示する。
- 捨て牌は画面内にきれいに収まるよう、横一列に表示する。
- プレイヤーの手牌は画面下部に横一列で表示する。
- CPUの手牌は画面上部に横一列で表示する。
- ツモ牌は、元の手牌から少し離して表示する。
- プレイヤー側の表示色は青系、CPU側の表示色は赤系とする。

### 6.3 牌の描画

- 牌は画像を使用せず、文字と図形で描画する。
- 牌は白い四角形を基本とし、角を少し丸くする。
- プレイヤーとCPUの牌は同じ大きさで表示する。
- 萬子は赤、筒子は青、索子は緑、字牌は黒で表示する。
- 数牌は「一萬」「二筒」「三索」のように漢数字と漢字で表示する。
- 字牌は「東」「南」「西」「北」「白」「發」「中」と漢字で表示する。
- CPUの牌背はオレンジに近い黄色とする。
- 鳴き牌はプレイヤー・CPUともに同じ向きで表示する。

### 6.4 ドラ表示

- ドラ表示牌は1枚とする。
- ドラ表示牌は対局開始時に自動でめくる。
- ドラ表示牌の次の牌をドラとして数える。
- 数牌は萬子・筒子・索子ともに1→2→3→4→5→6→7→8→9→1の順とする。
- 風牌は東→南→西→北→東の順とする。
- 三元牌は白→發→中→白の順とする。
- 裏ドラとカンドラは使用しない。

## 7. 状態と終了条件

- タイトル画面、対局中、局結果表示、ゲームクリア、ゲームオーバーの状態を持つ。
- 東四局終了後、親・子の最終持ち点を比較して勝敗を決定する。
- プレイヤーの勝利、CPUの勝利、引き分けを結果として表示する。
- 対局終了後の状態は、クリックでタイトル画面へ戻る。
