# 設計

## 画面上に登場するオブジェクト

- 的
- 射撃カーソル
- 残り時間
- スコア

## オブジェクトが持っている情報

- オブジェクト:持っている情報
- 的:座標(x,y),移動方向,移動速度,出現からの経過時間
- 爆弾:的と同じ座標・移動方向・移動速度・大きさ,黒一色の外観,白い縁,爆発済み状態
- 射撃カーソル:座標(x,y),射撃クールダウンタイム(秒)
- HUD:残り時間(秒),スコア,コンボ数

## 状態の移り変わり

ゲームの起動時はタイトルの状態

タイトル --スペースキーを押した時--> プレイ中
プレイ中 --残り時間が0かつ撃破数が20以上-->> ゲームクリア
プレイ中 --残り時間が0かつ撃破数が20未満-->> ゲームオーバー
ゲームクリアとゲームオーバー --スペースキーを押した時-->> タイトル

## パラメータ関係

残り時間 = 30秒
クリア必要スコア = 30000点
的1個の基本点 = 100点
射撃クールダウン = 0.2秒
的出現間隔 = プレイ開始時0.5秒から制限時間終了時0.1秒まで、30秒間で均等に短縮
的自然消滅時間 = 4秒
的自然消滅アニメーション = フェードアウト
最大同時的出現枚数 = 20枚
的移動方向 = 出現時に左右方向、上下方向、または左右と上下の両方からランダムに決定し、固定
的移動速度 = 出現時に100から300px/sの範囲でランダムに決定し、固定
的半径 = 33.6px
的の反射範囲 = HUDと重ならない範囲
的と的の衝突 = 的同士が重なった場合に反射
HUDフォント = 等幅フォント
結果画面のスコア表示位置 = 画面中央下
コンボ継続時間 = 2秒
コンボ表示位置 = 射撃カーソルの横
プレイ中の文字サイズ倍率 = 1.8倍
撃破スコア表示時間 = 1秒
爆弾出現確率 = 25%
爆発範囲 = 爆弾の半径の6.5倍
爆発アニメーション時間 = 0.2秒
爆弾爆発アニメーション時間 = 1秒
爆発アニメーション不透明度 = 0.9
