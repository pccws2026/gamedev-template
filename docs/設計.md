# 設計

## 登場するもの

- プレイヤー
- 雑魚敵
- ボス
- プレイヤーの弾
- 敵の弾

## 持っている情報
| オブジェクト | 持っている情報 |
| ------------ | -------------- |
| プレイヤー | 座標(x,y)、移動速度、残りHP、長押し時弾発射待ち時間、連打時弾発射待ち時間、被弾時のスコア減少量、弾の発射位置(x,y):プレイヤーの右端中心 |
| 雑魚敵 | 座標(x,y)、移動速度、残りHP、弾発射の待ち時間、撃破時のスコア増加量 |
| ボス | 座標(x,y)、移動速度、進行方向、行動パターン、プレイヤーの座標(x,y)、弾発射待ち時間、残りHP、撃破時のスコア増加量、出現中かどうか |
| プレイヤーの弾 | 座標(x,y)、移動速度、進行方向、ダメージ |
| 敵の弾 | 座標(x,y)、移動速度、進行方向、ダメージ、雑魚敵の左端中心の座標(x,y) |
| HUD | スコア、経過時間 |

## 移り変わりの条件

- タイトル -- Enterキー --> プレイ中
- プレイ中 -- プレイヤーHPが0 --> ゲームオーバー
- プレイ中 -- ボスHPが0 --> クリア
- ゲームオーバー -- Enterキー --> タイトル
- クリア -- Enterキー --> タイトル

## パラメータリスト

### プレイヤー
- 移動速度 : 500
- 長押し時弾発射待ち時間 : 20f 
- 連打時弾発射待ち時間 : 5f
- 最大HP : 20
- ダメージ時の無敵時間 : 30f
- ダメージ時のスコア増減量 : -30
- 最大出現数 : 1

### 雑魚敵
- 移動速度 : 300
- 弾発射待ち時間 : 90f
- 最大HP : 2
- プレイヤー接触時にプレイヤーへ与えるダメージ : 2
- 撃破時のスコア増減量 : +60
- 最大出現数 : 10
- 出現間隔 : 60f

### ボス
- 行動パターン数 : 2
- 行動パターンの切り替わり時間 : 300f
- 最大HP : 50
- 撃破時のスコア増減量 : +500
- 出現までの経過時間 : 1200f
- 最大出現数 : 1
- 前半 --> 後半へ切り替わるHP : 20以下

#### 前半
- 弾発射待ち時間 : 30f
- 行動パターンAの移動速度 : 400
- 行動パターンBの移動速度 : 230
#### 後半
- 弾発射待ち時間 : 20f
- 行動パターンAの移動速度 : 600
- 行動パターンBの移動速度 : 270

### プレイヤーの弾
- 移動速度 : 1200
- ダメージ : 1
- 最大出現数 : 50
- 発射時のスコアの増減量 : -2

### 敵の弾
- 移動速度 : 1200
- ダメージ : 1
- 最大出現数 : 40

### その他
- ステージ数 : 1面
